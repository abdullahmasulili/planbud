## Native regressions resolved

Retained Plan and Transactions tabs refresh source projections on focus. Plan preserves dirty drafts for explicit discard/reload; Transactions refreshes new/renamed categories while retaining the selected month and filter. The native fresh-setup sequence reproduced the category bug; a failing-then-passing host interaction protects the fix. Queued writes capture a connection session before joining the FIFO; committed replacement/reset invalidates old writes before source work, while rollback preserves valid queued edits.

Android release optimization removed the SDK exception whose class name defines the picker-cancellation code. The observed native cancellation failure became a passing cancellation followed by a successful export after a narrow CNG-generated keep rule. Other failures still report failure. Recovery inputs explicitly disable Android autofill. A top-only safe-area wrapper fixed the restore notice's status-bar overlap, verified after clean-install recovery.

Only labeled published cryptographic vectors and synthetic records were used. No real recovery phrase was generated or captured during UI automation. The current signed production APK was rebuilt after qualification fixes and passed the decompressed-member scan; it contains neither diagnostics nor synthetic test imports.

## Security and operation

The live SQLite database is app-private and is not encrypted in this MVP. Exports use native AES-GCM and HKDF-SHA-256 from the original 128-bit mnemonic entropy. Both the file and phrase are required; a documented format cannot guarantee decryption exclusively by this app. Import authenticates, validates and previews before explicit replacement. Clearing local data never deletes external backups.

Containers are limited to 16 MiB and snapshots to 50,000 source records including nested category limits. Exceeding a limit fails without truncation. Retain the ignored private signing pair for future updates; it is separate from recovery words. The APK and its relative-filename checksum are in `dist/android/`.

No external ticket. No commits, pushes or pull requests created. Remote required-check settings and store distribution were not configured.
